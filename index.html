เปิด Reading mode ใน Edge

  1. เปิดไฟล์ แล้วกดปุ่ม «Reading mode (Edge)» เพื่อสลับเป็นมุมมองอ่านต่อเนื่อง
  2. กด F9 หรือคลิกไอคอนรูปหนังสือที่แถบที่อยู่ของ Edge
  3. ใน Reading mode ใช้ «อ่านออกเสียง» และ «ตัวเลือกข้อความ» ของ Edge ได้
  4. กด «กลับมุมมองแบ่งหน้า» เมื่อต้องการใช้การแบ่งหน้าและเสียงอ่านของแอปอีกครั้ง

เว็บไซต์ไม่สามารถสั่งเปิด Reading mode ให้อัตโนมัติได้ เมื่อกด F9 แอปจะพยายามสลับเป็นมุมมองต่อเนื่องให้เอง ถ้ายังไม่เปิด ให้กดปุ่มสลับก่อนแล้วกด F9 อีกครั้ง เอกสารที่สั้นมากหรือหน้าที่เปิดผ่าน file:// อาจไม่แสดงไอคอน Reading mode

แปลเป็นภาษาไทยใน Edge

  1. เปิดไฟล์ แล้วตรวจว่า «ภาษาต้นฉบับ» ตรงกับเอกสาร
  2. กดไอคอนแปลภาษาที่แถบที่อยู่ของ Edge หรือคลิกขวาแล้วเลือกคำสั่งแปล
  3. เลือกภาษาปลายทางเป็น «ไทย»
  4. กด «อ่านจากหน้านี้» เพื่อฟังฉบับแปลด้วยเสียง Premwadee

เว็บไซต์ไม่สามารถสั่งให้ Edge แปลอัตโนมัติได้ และคำสั่งแปลอาจไม่ปรากฏเมื่อเปิดหน้าเว็บผ่าน file://
